# Statistical Programming Coursework

This repository contains R scripts developed for the Statistical Programming coursework. The collection focuses on implementing fundamental statistical measures, data manipulation techniques, and linear algebra operations using the R programming language.

## Overview

The repository is organized into scripts that cover various topics including:

- **Descriptive Statistics**: Manual implementations of statistical measures such as weighted mean, geometric mean, and mean absolute deviation.
- **Linear Algebra**: Matrix operations including creation, transposition, calculating determinants, and solving systems of linear equations using matrix methods.
- **Data Structures**: Working with vectors, matrices, and data frames, including data extraction, filtering, and the use of apply functions for row and column operations.
- **Problem Solving**: Scripts dedicated to specific problems like air quality index calculation and conditional logic for age verification.

## File Descriptions

- `age_checker.R`: Implements logic for verifying age-based conditions.
- `air_quality_index.R`: Calculations related to air quality indices.
- `data-frames.R`: Demonstrates data frame creation, indexing, and filtering.
- `extract-matrix-elements.R`: Techniques for accessing specific elements, rows, and columns within matrices.
- `geometric-mean.R`: Custom function to calculate the geometric mean of a numeric vector.
- `matix-determinant.R`: Matrix operations including inversion and transposition.
- `matrices.R`: Introduction to matrix construction and row/column naming conventions.
- `mean-absolute-dev.R`: Custom function for calculating the mean absolute deviation.
- `peacewise-function.R`: Implementation of piecewise mathematical functions.
- `solve-linear-equations.R`: Solving systems of linear equations using the `solve()` function and matrix multiplication.
- `weighted-mean.R`: Custom implementation for calculating the weighted mean.

## Requirements

- R (version 4.0 or higher recommended)
- RStudio (optional, for `.Rproj` support)

## Usage

Each script is self-contained. You can run them in an R environment or RStudio by opening the file and executing the code blocks.

```r
source("weighted-mean.R")
```
